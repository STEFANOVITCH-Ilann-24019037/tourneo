Tourneo

Le dépôt est bien publié sur GitHub Pages ✅

L'application complète utilise un backend PHP (fichier index.php et routes /api/*), qui n'est pas exécutable sur GitHub Pages.

Pour utiliser toutes les fonctionnalités, lancez le projet localement :

composer install
php -S localhost:8080 -t public/

Puis ouvrez http://localhost:8080.
